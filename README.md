# Northstar Files

一个零依赖的服务器文件浏览与预览页面，重点支持视频流式播放和拖动进度。

## 启动

```bash
git clone <你的仓库地址> file-viewer
cd file-viewer
python3 server.py --root /需要共享的目录 --port 8989
```

当前服务器可将启动命令加入 `~/.bashrc`：

以后执行 `lfserver` 即可启动。浏览器打开 `http://127.0.0.1:8989`。

在其他服务器上使用时，请把别名中的程序路径和共享目录替换为对应服务器的实际路径，例如：

```bash
alias lfserver='python /opt/file-viewer/server.py --root /srv/files'
source ~/.bashrc
```

常用参数：

- `--root PATH`：网页可访问的根目录（默认为启动命令所在目录）
- `--host HOST`：监听地址（默认 `0.0.0.0`）
- `--port PORT`：端口（默认 `8989`）
- `--show-hidden`：显示以 `.` 开头的隐藏文件

## 支持

- 视频、音频：使用浏览器原生播放器，服务端支持 HTTP Range
- 图片、PDF：页面内预览
- 文本、JSON、YAML/YML：预览前 512 KB（JSON 自动格式化）
- SQLite 数据库（`.db`、`.sqlite`、`.sqlite3`）：只读浏览数据表、字段和分页数据
- 桌面端预览窗口可拖动右下角手柄调整大小
- 文件列表支持按名称、修改时间从新到旧或从旧到新排序
- ZIP 与 TAR 系列压缩包无需解压即可查看可折叠文件树（最多 10,000 项）
- 其他文件：显示信息并提供下载
- 软链接：共享目录内的软链接文件和文件夹可以正常浏览、预览与下载

应用会阻止 `..` 路径穿越。共享目录内的软链接会被跟随，因此软链接目标即使位于 `--root` 之外也可访问；请只在受信任的共享目录中放置软链接。若部署到公网，请在前面增加身份认证与 HTTPS 反向代理。
